# BGV Sounds Website

A multi-page website for BGV Sounds, a full-service audio house offering recording and production, sound branding, voiceover and session vocals, background vocals, and live sound.

**Live site:** https://bvg-studio.vercel.app



## Pages
- **Home:** introduces the studio and its services
- **About:** the studio's story and approach
- **Sessions:** the services on offer
- **Contact:** how to reach the studio
